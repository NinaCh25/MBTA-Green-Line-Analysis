# MBTA-Green-Line-Analysis
MBTA Green Line Travel Trends Analysis

-Overview-

This project analyzes travel-time data from the MBTA Green Line B branch. The analysis explores patterns in travel times and uses data visualization and statistical analysis to understand the performance and variability of travel along the line better.

-Dataset-

This project uses MBTA Green Line travel-time data.
The original dataset is not included in this repository due to its original source distribution. The notebook contains the analysis and results produced using the dataset.

-Methods-

The analysis was performed using Python and includes: 

  Data loading and cleaning
  Exploratory data analysis
  Statistical analysis
  Data visualization
  Examination of travel-time patterns and variability

Project Note:

This repository showcases the data analysis and visualization techniques used to explore real-world transportation data. The original dataset is not included in the repository.
